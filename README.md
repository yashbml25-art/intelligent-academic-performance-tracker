# Intelligent Academic Performance Tracker & Visualizer

## Project Overview

The Intelligent Academic Performance Tracker & Visualizer is a Python-based project designed to analyze and visualize student academic performance.

The system will process student marks, subject details, credits, and attendance to calculate grades, GPA/CGPA and provide a clear performance analysis.

## Objectives

- Calculate subject-wise percentage and grades
- Calculate GPA/CGPA
- Track student attendance
- Analyze strong and weak subjects
- Visualize academic performance using charts
- Generate an easy-to-understand performance report
